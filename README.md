# 🛒 ShopKart — Full-Stack E-Commerce Platform

> A modern multi-category e-commerce web application built with
> HTML, CSS, JavaScript, Bootstrap, Flask, SQLAlchemy and SQLite.

---

## 1. 🎯 TITLE

### ShopKart

ShopKart is a full-stack marketplace where customers can browse
products, search and filter items, manage a cart and wishlist,
place orders, and complete checkout.

Sellers can manage products and orders from a dedicated dashboard.

---

## 2. ❗ PROBLEM

Many beginner e-commerce projects are only frontend demonstrations.

ShopKart was built to demonstrate a complete full-stack workflow:

- 🔐 User registration and login
- 🛍️ Product browsing and search
- 🛒 Cart and wishlist
- 📦 Order management
- 🧑‍💼 Seller dashboard
- ✏️ Add, edit and delete products
- 💳 Razorpay Test Mode payment
- 🗄️ Database storage
- 🔑 JWT authentication

---
